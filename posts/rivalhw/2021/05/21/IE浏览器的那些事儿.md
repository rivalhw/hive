2020年5月20日，本该是恋人之间的520(中文谐音：我爱你)告白日，微软却正式宣布，

>IE 11 将在 2022 年 6 月 15 日终止支持，在 Windows 10 上 Microsoft Edge 是 IE 的未来。

作为一款曾经几乎占据绝大多数桌面系统的浏览器，却落得个爹不亲娘不疼的如今下场，究竟是何原因？

我第一次正式的、有特别深刻印象接触IE浏览器，大约是1998年，那时候也是我刚开始接触互联网。

![ie4.jpeg](https://images.hive.blog/DQmSMtj36yuoeNA8Bgddu64MGf4KPXD6xSP5HyHHdDkJwzW/ie4.jpeg)
IE 4.0

而当时如日中天、炙手可热的浏览器，正是浏览器的开天鼻祖，网景(netscape) 旗下的一款名为 Netscape Navigator 的浏览器。而在此之前，IE已经推出过几个版本，只是市场占有率一直都没有太大起色，直到微软在大约1997年的时候，使出了流氓招数，也就是其后来多次运用的杀手锏：将 IE 与 Windows 98 捆绑在一起免费提供，一段时间下来，抢占了不少 Navigator 的市场，要知道，这之前浏览器一直还需要付费购买的，既然现在有了IE这样免费的浏览器，还有几个人愿意再继续花钱付费去购买Navigator 浏览器呢？

从此Navigator 就开始一路走下坡路，即便后来netscape也曾宣布将Navigator 免费公开化，但已经晚了，最后依旧逃脱不了被市场逐渐淡忘的命运。

![Navigator1.gif](https://images.hive.blog/DQmaRQuMHYcT88Mn3eDYdexMxWf8RaLFzV7unpuRoBCHmtM/Navigator1.gif)
the pic resource from [baike.baidu.com](https://baike.baidu.com/pic/%E7%BD%91%E6%99%AF/70176/0/5327ce16150f0671972b43b1?fr=lemma&ct=single#aid=0&pic=5327ce16150f0671972b43b1)

IE 5.0推出于1999年，同时间陆续推出的有windows 2000 和 windows Me两款操作系统，不知道是不是之前的windows 98过于成功，备受市场火热和人们的喜爱，以至于后来的这两款操作系统当时的市场反响很弱，尤其是windows Me，我曾经也用过阵子，毫不客气地讲，windows Me就是一款被阉割过、整体非常奇葩的一款系统，兼容性和稳定性也非常差，以至于沦落到被嘲笑只能家庭用来扫雷和娱乐的尴尬地步。

城门失火殃及池鱼，windows 2000 和 windows Me的疲软，也间接影响到了IE 5.0，导致这个版本的浏览器也是反响平平。

直到2001年，微软推出了新版本浏览器，也就是日后多年风靡的IE 6.0，为什么说这款浏览器风靡多年呢？看看但是其在市场的占有率你就能明白，毫不夸张地讲，在ie 6.0开始时代，微软在浏览器市场上，几乎没有任何有竞争力的对手，国内当时也出了许多浏览器，但几乎都是使用的ie6.0的内核，然后再外面包装了个新皮肤而已。

![ie6.jpeg](https://images.hive.blog/DQmZTNppCSAtHNSCEetD1hrrypksJgjvURFRGPJJTUtmMN8/ie6.jpeg)
ie6.0

所谓成也萧何败萧何，IE6.0让微软获得了巨大的成功，也是因为IE 6.0在市场上过于受欢迎，让微软的开发团队有些得意忘形，以至于后续的新版本浏览器一直迟迟未见推出，但时代在发展，网络科技也一直在进步，尤其是2004年后，互联网的发展更是迅猛，也就在同一时间，新的浏览器firefox，也就是我们熟悉的火狐开始异军突起，陆续开始占领市场。

>2004年2月9日，Mozilla Firebird决定改称Mozilla Firefox，简称Firefox 


微软这时候发现情况不妙，赶紧于2006年发布了新版IE 7.0，其中有个最引人注目的功能之一，就是tab分页浏览功能，但就是这个功能，在firefox上早在几年前就已经有了，因此可见IE开发团队的反应迟钝，或者说太缺乏对于这方面特性的敏感。

由此IE浏览器的衰落，可见一斑，从此之后，IE浏览器的市场就逐渐开始被蚕食。

2008年，google推出了自家的浏览器，也就是后来三分天下的chrome浏览器，从此IE、firefox和Chrome，几乎占据了整个浏览器市场。

而在Firefox和Chrome的不断进攻和蚕食下，IE浏览器疲于应付，也似乎只有招架之力，而无还手之力。

就这样，IE浏览器的市场份额更是一路下滑，即便后来微软也推出了新的版本IE8.0、IE9.0。。。

直到最后的IE 11.0，显然对于靠IE再次翻身，打败Firefox和Chrome ，重新一统江湖这样的想法，连微软自己都觉得毫无希望可言了。

但IE在过去的近二十多年里，毕竟也给微软立下过汗马功劳，想要说声放弃，真的很难。微软又推出了新的浏览器Edge，但也是一直半死不活，好在微软家大业大。

但几年下来，估计连微软自己也绝望了，于是就出现了开头的一幕，
