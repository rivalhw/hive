**Import Wallet 导入旧钱包**

![2-0.png](https://images.hive.blog/DQmb4KaGZ6aSv9SBq1dq4uctmEACHPBY7kUvLj8KA4FD8s2/2-0.png)

 

如果之前有使用过Meta Mask，则选择左边 Import Wallet

1> Import Wallet

 

![2-1.png](https://images.hive.blog/DQme5LqtaUuQ1MiguuXEvd2y145s7DSB1jWWwxtGHVwjG2h/2-1.png)

输入方才记录的助记词，记得按顺序输入

输入方才设置的密码

![2-1-2.png](https://images.hive.blog/DQmPJWSGhfXpLyhwT4vJ9YLcQGCjMQVRYuU3RcKQMcPw5T6/2-1-2.png)

 

2>完成后点击 Restore 按钮，正式进入到Meta Mask钱包界面了

 

![2-2.png](https://images.hive.blog/DQmeqShwvv3H1rYY3tJzeXYjoNuxcfer9yhMGtgfHhBqzN9/2-2.png)

**如何在MetaMask中增加PolyGon主网?**

打开MetaMask后，出现如下图，

 

![3-0-1.png](https://images.hive.blog/DQmdDEZioDKo5aaUikkYtnudUrbnF3TK4BxdWebepBz3YQs/3-0-1.png)

或者如下图

 

![3-0-2.png](https://images.hive.blog/DQmdUS615q1RfHHoXdJJCdTv5YXgTe9riQqgAuf3VqSgtLf/3-0-2.png)

1> 点击红色画圈(Ethereum Mainnet)部分，见如下图

 

![3-1.png](https://images.hive.blog/DQmaPWFpNoh6SwhADLuL6Dt8DL7XuGVbUYct4mv78VhRVET/3-1.png)

2> 选择点击 Custom RPC，出现如下图

 

![3-2.png](https://images.hive.blog/DQmYCbLHWoMfhwPzfrgUQ2hdN4BXtgyYwcqLSiTmKEuYVR8/3-2.png)

3> 添加PolyGon主网信息，如下图

 

![3-3.png](https://images.hive.blog/DQmZZGnfAGG33eLmLjY6EUqodPmffb4bo6HfK6NR9PH77Uu/3-3.png)

Network Name：Matic Mainnet

New RPC URL：https://rpc-mainnet.maticvigil.com/

Chain ID:137

Currency Symbol (optional):MATIC

Block Explorer URL (optional):https://explorer.matic.network/

4> 点击 Save按钮，返回主界面，见如下图

 

![3-4.png](https://images.hive.blog/DQme1PrtL3wvCwuRpg7uCFwK6jSspMBVKSQqKubU8WE6RtB/3-4.png)

大功告成！ :)
