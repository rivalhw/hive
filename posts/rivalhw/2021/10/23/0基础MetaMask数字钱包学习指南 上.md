**如何安装数字钱包MetaMask？**


1>打开浏览器，输入MetaMask 地址: https://metamask.io，如下图，
 
![001.png](https://images.hive.blog/DQmZS6yvfEzT9DbGeQeCbLtjLydbjju2iiQMGRfVddUm68L/001.png)


2>点击 DownLoad 按钮，如下图，
 
![002.png](https://images.hive.blog/DQmaqwujvJ2DUJX4NBEcX6zJ4vTGiV3RH7JSuBw3B6S7gNA/002.png)


3>选择适合自己浏览器类型，如当前是firefox浏览器，直接点击Install MetaMask，进入如下图，
 
![003.png](https://images.hive.blog/DQmW75yHF1fFzHMdeHfjijwCRAZX1FXBdC3oCK56fQH3Au3/003.png)


4>点击 Add to Firefox

![004.png](https://images.hive.blog/DQmV6KM4PZBc1PX6PtfDdTeXzVDWHjZHYch6YWoaVAQb8dz/004.png)

 

5>点击 Add，如下图
 
![005.png](https://images.hive.blog/DQmZ8uT2ERdVTXEXDZxdzbwn8CXCp6c35dxFPSUgj9nZA9a/005.png)


6>点击如上图右上角![image.png](https://images.hive.blog/DQmQ5eyGueEwKDa97qywYDthrsRvmmiRR1fFuouSyiBCsjV/image.png)图标，打开Meta Mask，如下图，
 
![006.png](https://images.hive.blog/DQmb4KaGZ6aSv9SBq1dq4uctmEACHPBY7kUvLj8KA4FD8s2/006.png)



**如何使用Meta Mask？**


第一次打开Meta Mask后，会出现如下图，
 ![2-0.png](https://images.hive.blog/DQmb4KaGZ6aSv9SBq1dq4uctmEACHPBY7kUvLj8KA4FD8s2/2-0.png)

1、 Create Wallet



1>点击 Create Wallet，见如下图，
 
![2-1.png](https://images.hive.blog/DQmdQVnfq2ewsdEPE7NwQhRzoS4wVf5JT7hZKrjMontZFAh/2-1.png)

2> 点击 I Agree 按钮，见如下图
 
![2-2.png](https://images.hive.blog/DQmdKz28uC2TFmhKyRsx6RGFuDNz7RXVddnxwdV3KaofHgi/2-2.png)

输入你的密码和确认密码

![2-2-1.png](https://images.hive.blog/DQmRLrojDv7CWBWQdsKP1Kydq99fcscPmLru5Zk1sozq7MQ/2-2-1.png)

 

注意，密码至少为8个字符或以上

3> 点击 Create 开始创建钱包
 
![2-3.png](https://images.hive.blog/DQmasxPqyKbbRmUAuQXX2EBF2MTzFXoF6fWqRv2GKJSHR5T/2-3.png)

看视频，不想看视频的话，这步可直接跳过

点击 Next，见如下图
 
![2-3-1.png](https://images.hive.blog/DQmY5H9Jk5KFGL52sxXRjykh12CWAGnxXGMcjAuao1RHsSj/2-3-1.png)


4> 保存助记词
 
![2-4.png](https://images.hive.blog/DQmcQmog8wEfZsRPVAbX444Dsfjp87Wp7fKZqgjNzhEyLdB/2-4.png)

记得按顺序保存好你的助记词，如上图部分。

非常重要！非常重要！非常重要！
5> 确认助记词
 
![2-5.png](https://images.hive.blog/DQmeT183CZAFb8BkYWrHCDjfHKKAjakZUDT58o6UHqzboEa/2-5.png)


![2-5-1.png](https://images.hive.blog/DQmPoASY3pNKYmTnQrkNNamcWPsJrD2zqRVPD3sd1GE7JZG/2-5-1.png)

 
6> 助记词确认后，点击 Confirm按钮
 
![2-6.png](https://images.hive.blog/DQmYnHqkqfD5SMLXzmNcJnF1BbmZ6XavXDVD5z4LSoUPZqR/2-6.png)


7> All done
大功告成！ :)
