前几日的时候，需要购买个服务，我在网上转了半天，好不容易找到两个认为还不错的网站，准备购买试下。

结果是，购买成功之后，发现无法使用。我尝试联系网站的客服，发现试了半天，始终显示无法连接上，但是奇怪的是，那个客服的状态前边却一直提示我，大意是说前边只有2人在等待，让我误以为很快能轮到我，最后发现无果只好放弃。

我又看到网站上有邮件的联系方式，想到老外多比较习惯邮件往来，便将自己的问题整理了下，发了邮件给对方。

次日，收到对方的邮件，建议我安装后如下测试下，

>Test steps:
1. Press win+R
2. Input "cmd", then press Enter
3. Copy the test command and paste it in Windows command, then press Enter.
Your test command:
curl -x 154.214.16.175:2340 -U "USERNAME:PASSWORD" ipinfo.io
(Please remember to replace the USERNAME and PASSWORD you set into the corresponding fields)

Please screenshot the result and send the pictures back to me.

我试了下，发现无果，截图给对方。

这次可能对方正在上班中，很快回复了我邮件，
>Please copy this test command to me and I will test it on my side

我心想，截图上不是有信息吗？自己直接复制下，或者手动打下不更快吗？就那么一行命令，还专门发邮件让我复制给他。。。这。。。

想着只要能用，还是自己复制后再发邮件给对方吧，反正也就动动手不过一分钟的事情。

这样反复来回几次，依旧不行。


![001.png](https://images.hive.blog/DQmUmf2NG6WxqiQJ15c59NwNLoYPDGeAW8xVZL7g3DfGc6z/001.png)

但对方说他那边可以用，还“贴心”地附上了截图信息，我看了下，好像对方那边真的能用。

但这有毛用啊？我这边不能用啊。


最后无奈之下，对方发邮件问我，是不是在China?

我如实回答说是，然后对方悠悠地回复了我新邮件，

>Our service need to be used in a non-Mainland China network environment.

大意是说，他们提供的服务不能在中国大陆使用。

妈蛋！你不早说！网站上也没有提示啊？？？

我回复邮件问对方，那既然这样，不能用的话，能不能给我退款？

对方毫不犹豫发了邮件告诉我，开头一个大写的，

Sorry！... 


囧。。。这不讲理呀！囧。。。

得！就算我花小钱买教训了。

另外一个网站，为了谨慎期间，我开始购买的时间较短，想着测试后没问题，再考虑延长服务时间。

这次购买之前，我认真地把官方网站的资料都大致看了一遍，文档也扫了一遍，看到说国内是可以使用，我心里有些放心。

但购买之后，尝试仍无法使用。

啊？？？这。。。

联系对方客服，这次客服是在线那种，折腾了好一会，这次终于可以用啦！

看来以后购买服务，除非知名网站，一定要提供有在线客服，只有邮件往来问答那种就免了，太麻烦也太折腾人。

另外说下，在国外的网站购买，尽量使用支付宝或paypal支付，避免直接使用信用卡支付，出现被盗刷或者被恶意扣款的现象，我多年前就中招过，对方还是家较为知名的企业，网站上却实在找不到取消服务的地方，后来还是把那张卡挂失才算终止。囧
